start for
From the start, the GPU tries every input every tick, keeps the attempts that follow your line best (a guide, not a rail) and then heads back to the run. An attempt that becomes exactly equal to a later moment of the run is a proven shortcut: it goes to the optimizer, which checks it again.
Legend & keys
  • The level in Everybody Edits' own graphics (from your eeo-tas folder, ⚙ below) · doors, gates, switches and the numbers on coin and death doors follow the run · a coin disappears when the best run takes it (a faint coin marks where it was)
  • Smiley: the current best run · pale smiley: your original .eetas (ghost), same in-game time · yellow trail: the last 0.8 s · thin line: the whole route
  • Yellow ball: the current best run · pale ball: your original .eetas (ghost), same in-game time
  • Blocks in EE's own minimap colors (background dimmed) · triangles: arrows (gravity) · small dots: dots · orange chevrons: boosts
  • Purple rings: portals (white dot: random exit) · coins disappear when the best run takes them · doors: filled = closed, outline = open (number = coins / deaths needed) · red diamonds: spikes · green checker: the finish
  • Space play/pause · ←→ 1 s (Shift: 1 tick; or the step buttons, hold to repeat) · +- zoom · 0 fit level · F follow · G ghost · Esc close · drag to look around, wheel/pinch to zoom
